Ein Skill lädt sein Wissen erst, wenn es gebraucht wird

Vorhersage: Ein Agent hat 50 Skills installiert. Was davon liegt beim Start im Kontextfenster?

Begriffe

Skill: ein Ordner mit einer Anleitung für eine wiederkehrende Aufgabe, bei Bedarf ergänzt um Skripte, Vorlagen und Beispielmaterial.

SKILL.md: die Pflichtdatei jedes Skills; sie beginnt mit Name und Kurzbeschreibung und enthält danach die eigentliche Anleitung als einfachen Text.

Metadaten: die Angaben über den Skill, also Name und Kurzbeschreibung, an denen der Agent erkennt, wann der Skill zur Aufgabe passt.

Kontextfenster: alles, was das Modell in diesem Augenblick vor sich hat; was nicht darin steht, existiert für die Antwort nicht.

Größenordnungen laut Anthropic-Dokumentation: Name und Kurzbeschreibung belegen etwa 100 Tokens je Skill, die Anleitung auf Stufe 2 bleibt unter 5.000 Tokens, und Zusatzdateien kosten nichts, solange der Agent sie nicht liest (Anthropic, o. J.). Für 50 installierte Skills liegen beim Start also rund 5.000 Tokens auf dem Tisch.

Ein offener Standard

Anthropic hat Agent Skills am 18. Dezember 2025 als offenen Standard veröffentlicht, damit derselbe Skill-Ordner in verschiedenen Werkzeugen funktioniert (Zhang et al., 2025). Die Übersicht des Standards führt auch Werkzeuge anderer Anbieter auf, die das Format unterstützen, darunter ChatGPT und Codex von OpenAI, Gemini CLI von Google und GitHub Copilot (Agent Skills, o. J.).

Unterschied zu RAG

RAG holt Wissen per Suche in eigenen Quellen, ein Skill holt Arbeitsanweisungen per Beschreibung.
